# Insurance Denial Appeal Letter CLI

A local-first Python CLI that drafts insurance denial appeal letters from
policy and claim details using a configurable OpenAI-compatible endpoint
(default Ollama).

Built and maintained by **Asdale Dynamics, LLC** — beginner-friendly AI
education, books and guides, and practical tools.

## What it does

You supply the facts of a denied health insurance claim (policyholder,
member ID, claim number, date of service, provider, codes, amounts, denial
reason, clinical notes, supporting documents). The tool drafts a formal,
professional appeal letter ready to print or edit before you send it.

## Education only — never medical advice

Every letter printed by this tool includes an **education-only disclaimer**:

> This appeal letter is generated by an automated tool for educational and
> administrative use only. It is NOT legal, financial, or medical advice.
> Nothing in this letter should be used to diagnose, treat, or prescribe
> medical care. Always consult a qualified attorney, your insurance broker,
> or a licensed healthcare professional before submitting any appeal or
> making decisions about your coverage or care.

This tool never sends anything automatically. It prints the letter to your
terminal (and optionally to a file). You review it, edit it, and decide
whether and when to submit it.

## Local-first by default

The default endpoint is a local Ollama instance at `http://localhost:11434`.
No API keys are required, and no data leaves your machine unless you
explicitly configure a remote OpenAI-compatible endpoint.

## Usage

Draft a letter using the built-in template (no LLM endpoint needed):

```bash
insurance-appeal --no-llm \
  --policyholder-name "Jane Doe" \
  --dob "1980-01-01" \
  --member-id "MEM123456" \
  --address "123 Main St, Indianapolis, IN 46202" \
  --phone "317-555-0100" \
  --claim-number "CLM-99999" \
  --date-of-service "2026-01-15" \
  --provider "Meridian Health" \
  --procedure-codes "99213" \
  --diagnosis-codes "E11.9" \
  --amount-charged "250.00" \
  --amount-paid "0.00" \
  --denial-reason "Not medically necessary" \
  --denial-reason-detail "Service deemed not medically necessary." \
  --clinical-notes "Patient presents with uncontrolled type 2 diabetes." \
  --supporting-docs "Medical records, physician letter of necessity." \
  --requested-action "reverse the denial and authorize payment" \
  --output letter.txt
```

Draft using a local Ollama endpoint (default `http://localhost:11434`):

```bash
insurance-appeal \
  --policyholder-name "Jane Doe" \
  --claim-number "CLM-99999" \
  --denial-reason "Not medically necessary" \
  --model llama3.1 \
  --output letter.txt
```

Read details from a JSON file:

```bash
insurance-appeal --from details.json --output letter.txt
```

Check that your endpoint is reachable:

```bash
insurance-appeal --healthcheck
```

### Key flags

| Flag | Purpose |
|------|---------|
| `--no-llm` | Use the built-in template instead of an LLM endpoint |
| `--endpoint` | OpenAI-compatible base URL (default: `http://localhost:11434`) |
| `--model` | Model name (default: `llama3.1`) |
| `--output` | Write the letter to this file (also printed to stdout) |
| `--from` | Read details from a JSON file |
| `--healthcheck` | Check endpoint reachability, then exit |

### Environment variables

- `OLLAMA_BASE_URL` / `INSURANCE_APPEAL_BASE_URL` — default endpoint base URL
- `OLLAMA_MODEL` / `INSURANCE_APPEAL_MODEL` — default model name

CLI flags always win over environment variables.
